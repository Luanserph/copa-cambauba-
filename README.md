# 🎵 Escola Modelar Cambaúba - Músicas da Copa

Uma aplicação web moderna e interativa desenvolvida para apresentar as produções musicais e cordéis dos alunos do 6º ano (**Turmas 601 e 602**) da **Escola Modelar Cambaúba**, no contexto do projeto pedagógico sobre a Copa do Mundo.

---

## 🚀 Demonstração

O projeto está publicado e disponível online através da **Vercel**:
- **Repositório GitHub:** [Lucas-dev100/copa-cambauba-](https://github.com/Lucas-dev100/copa-cambauba-)

---

## ✨ Funcionalidades

- **Player de Áudio Completo:**
  - Controles de reprodução: Play, Pause, Próxima faixa e Faixa anterior.
  - Barra de progresso interativa para avançar ou retroceder a música (*seek bar*).
  - Controle de volume integrado.
  - Reprodução contínua automática ao término de cada faixa.
- **Lista de Reprodução Organizada:**
  - Faixas agrupadas pelas turmas (**Turma 601** e **Turma 602**).
  - Indicação visual da música em reprodução em tempo real.
  - Seleção direta de qualquer faixa com um único clique.
- **Design Moderno e Responsivo:**
  - Interface com tema *dark*, gradientes refinados e efeitos de *glassmorphism*.
  - Otimizado para telas de smartphones, tablets e computadores.

## 🛠️ Tecnologias Utilizadas

- **HTML5** & **JavaScript (ES6+)** - Estrutura e lógica do player de áudio.
- **Tailwind CSS** - Estilização responsiva, componentes e efeitos visuais.
- **Font Awesome 6** - Ícones vetoriais.
- **Git & GitHub** - Controle de versão e hospedagem do código.
- **Vercel** - Hospedagem estática com entrega contínua (*Continuous Deployment*).

---

## 💻 Como Rodar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/Lucas-dev100/copa-cambauba-.git
   cd copa-cambauba-
   ```

2. Abra o arquivo `index.html` em qualquer navegador:
   - Dê um duplo clique no arquivo `index.html`, ou
   - Use a extensão **Live Server** no VS Code / IDE.

---

## 🔄 Fluxo de Atualização Automática (Deploy)

O projeto está integrado à **Vercel**. Toda vez que uma alteração é enviada para a branch `main` no GitHub (`git push`), a Vercel detecta a atualização automaticamente e recompila o site no ar em segundos!
